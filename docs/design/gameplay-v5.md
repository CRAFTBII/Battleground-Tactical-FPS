# 玩法重设计 v5 · RAID「黑港行动」

> 状态：设计稿（先定玩法，再改代码）  
> 目标平台：桌面浏览器 / 键鼠，单人 + AI 小队  
> 单局时长：10–15 分钟  
> 关联：[地图设计板](raid-site-a-layout.html) · [建筑套件](building-kit-v5.md) · [参考案例](fps-references.md)

## 0. 结论先行

当前 v4 的问题不是“碰撞不够准”或“建筑不够多”，而是**没有一个值得重复玩的循环**：

- 三张 300m 城镇，玩家从出生点跑 30–60 秒才遇到第一个敌人；
- 20 个 AI 同时寻路，行为只能做得很粗，最后变成两团人隔街对射；
- 占点/击杀/生存三种任务混在一起，但没有回合、目标、撤离或失败压力；
- 建筑是运行时拼的盒子，缺少可读的入口、窗口、室内动线和战斗目的。

v5 改成**小地图、少单位、强目标、可失败**的战术 RAID：

> 玩家带 3 名 AI 队员，从南侧插入黑港站点；在守军巡逻网中完成“情报站 A”和“指挥楼 B”两个目标，然后从北侧撤离。  
> 警报每升一级，守军增援和包抄路线增加；玩家要决定是继续搜刮，还是趁现在走。

**为什么是 RAID：**

- 复用现有 Game / Combat / AI / 倒地救援 / 战利品系统；
- 单人 + AI 小队比 5v5 竞技更可控，不要求机器人达到真人战术水平；
- 目标 + 撤离天然提供节奏、失败条件和“再来一局”的动机；
- 160m 小地图可以把每栋建筑做成真正的战斗空间，而不是背景板。

---

## 1. 设计支柱

1. **读空间**：三条进攻路线、清晰地标、可记忆的室内结构；玩家 30 秒内知道“我在哪、下一步去哪”。
2. **做计划**：入口、窗口、破门、烟/闪、队员分工；同一目标至少有 3 种解法。
3. **小队生存**：玩家和 AI 都会倒地，救援要付出血量/时间/弹药代价；死亡不复活。
4. **风险与撤离**：目标和战利品都想要，但警报、增援和撤离窗口逼玩家做取舍。

非目标（v5 MVP 不做）：

- 不做 20v20 / 64 人征服；
- 不做开放世界、载具、建筑破坏；
- 不做复杂经济/跳蚤市场/永久掉落；
- 不做 5v5 真人竞技匹配（AI 达不到竞技级之前不做）。

## 2. 核心循环

```
选择插入路线
   ↓
潜入 / 清理巡逻（可避开）
   ↓
目标 A：情报站（交互 8s，触发 1 级警报）
   ↓
目标 B：指挥楼 2F（交互 10s，触发 2 级警报）
   ↓
可选：搜刮 / 救队员 / 破坏补给
   ↓
北侧撤离（守军增援 + 包抄）
   ↓
结算：目标、战利品、击杀、用时、队员存活
```

### 2.1 单局节奏

| 时间 | 阶段 | 玩家体验 |
|---|---|---|
| 0:00–1:30 | 插入 | 安静、听脚步、选路线；远处有巡逻和狗叫/无线电 |
| 1:30–4:00 | 接近 A | 第一次交火；守军听声增援；玩家决定强攻还是绕后 |
| 4:00–6:30 | A 点 | 室内 CQB；交互读条；1 级警报；QRF 从北侧出发 |
| 6:30–9:30 | 转点 B | 三条路线可选；守军开始占高位；队员可能倒地 |
| 9:30–12:00 | B 点 | 2F 战斗；2 级警报；撤离窗口开始倒计时 |
| 12:00–15:00 | 撤离 | 守军最后一波 + 包抄；玩家在“再搜一个箱子”与“现在走”之间决策 |

### 2.2 胜负

- **全胜**：完成 A+B，至少 1 名队员（含玩家）撤离。
- **部分成功**：完成任意 1 个目标并撤离；奖励减少，解锁后续情报。
- **失败**：小队全灭、撤离窗口关闭、或超过 15 分钟未撤离。
- **隐藏奖励**：全员存活撤离、无警报完成 A、带走“机密箱”。

> 失败不是“回主菜单重开”，而是结算页直接给“再跑一次 / 换路线 / 降难度”。

## 3. 地图：黑港站点 A（160×160m）

> 详见 [raid-site-a-layout.html](raid-site-a-layout.html)

### 3.1 三层空间

- **地面层**：主街、集装箱堆场、仓库、行政楼大厅；
- **中层**：仓库猫道、行政楼 2F、市场雨棚/连廊；
- **屋顶/高处**：仓库屋顶（可上）、行政楼屋顶（守军狙击位）、水塔/吊机（视野位）。

垂直度只做“可读的两层”，不做迷宫式五层。所有上层至少有两条上下路径（楼梯/外梯/破窗/屋顶缺口）。

### 3.2 三条进攻路线

| 路线 | 空间 | 优势 | 风险 | 适用 |
|---|---|---|---|---|
| **A 西线** | 集装箱迷宫 → 仓库 A → 西侧巷道 | 掩体多、近距离、可绕开主街 | 拐角多、容易被近距离伏击 | 霰弹/冲锋枪/烟雾 |
| **B 中线** | 南门 → 主街 → 市场 → 行政广场 | 距离短、目标明确 | 长枪线、狙击/机枪压制 | 步枪/狙击/烟雾 |
| **C 东线** | 排水渠 → 东仓库 → 行政楼侧门 | 隐蔽、可摸到 B 点侧后 | 低洼、出口少、被发现后难撤 | 潜行/侧翼/破门 |

三条路线在**市场十字**与**行政广场**交汇；交汇点是主要交火点（choke point），但每条路线都有至少一个“不经过交汇点”的侧翼连接。

### 3.3 目标点

- **A · 情报站（仓库西侧办公室）**
  - 一层，两个门 + 一个可破窗；
  - 室内有文件柜/桌子的低掩体；
  - 交互 8 秒，读条期间不能移动；
  - 完成后 1 级警报，北侧 QRF 出发。
- **B · 指挥楼（行政楼 2F 服务器房）**
  - 一层大厅 + 2F 服务器房；
  - 两条楼梯（主楼梯 / 外消防梯）+ 可破窗；
  - 交互 10 秒；
  - 完成后 2 级警报，撤离窗口 4 分钟。
- **可选 · 集装箱清单（西侧堆场）**
  - 需要撬锁 4 秒；给额外奖励，但会发出声音。

### 3.4 守军与巡逻

- 12–16 名守军，分 4 个巡逻区：南门、堆场、仓库、行政楼。
- 每区 2–4 人，1 名队长（无线电、呼叫增援）。
- 2 名固定高位：行政楼屋顶狙击、水塔观察。
- 1 个 QRF 小队（4 人）在北侧待命，警报后从北门/东侧包抄。
- 巡逻路线是**环形 + 停留点**，不是随机乱走；玩家可以观察 10–20 秒找空档。

## 4. 战斗与数值

### 4.1 目标 TTK

| 武器 | 身体 TTK | 爆头 | 定位 |
|---|---|---|---|
| 步枪 | 0.35–0.5s | 1–2 发 | 全能 |
| 冲锋枪 | 0.25–0.35s（近距离） | 2 发 | 室内/西线 |
| 霰弹 | 0.2s（<8m） | — | 破门/拐角 |
| 狙击 | 0.1s（胸） | 1 发 | 中线/高位 |
| 机枪 | 0.5s | 2 发 | 压制/守点 |

- 护甲吸收 50–60%，爆头倍率 2×；腿部减伤。
- 玩家 100 HP + 100 护甲；AI 守军 100 HP + 30–70 护甲。
- 不追求拟真弹道下坠；保留清晰命中反馈和声音。

### 4.2 武器/装备

- 主武器 1 + 副武器 1；手雷/烟雾/闪光各 1–2。
- 破门炸药：只能带 1 个，可开锁定的门/墙（预设 breach 点）。
- 医疗包：自愈/救人共用，稀缺；AI 医疗兵有额外包。
- 弹药：每局有限，守军掉落补充；鼓励捡枪。

### 4.3 倒地与救援

- 玩家/AI 倒地后 45 秒流血（当前 20 秒偏短，v5 拉长）。
- 救援 4 秒 + 消耗 1 医疗包；被救起 35 HP。
- 倒地可爬行、可被处决；AI 医疗兵优先救援，其他 AI 在安全时救。
- 全员倒地/死亡 = 失败，不复活。

## 5. AI 设计

### 5.1 守军 AI

| 状态 | 行为 |
|---|---|
| Patrol | 沿巡逻环移动，在停留点观察 3–6 秒 |
| Investigate | 听到枪声/脚步/破门 → 去最后已知位置，2–3 人一组 |
| Hold | 发现玩家后占据最近掩体/高位，不无脑冲 |
| Flank | 1–2 人从侧翼 nav link 包抄，正面保持压制 |
| QRF | 警报后从北侧出发，走预设增援路线 |
| Retreat | 低血/被压制时退到下一道防线，呼叫增援 |

关键：**不要所有 AI 共享一个目标点**。每个巡逻组有独立区域/侧翼，QRF 有独立路线。

### 5.2 玩家小队 AI

- 3 名队员：突击/支援/医疗（或狙击）。
- 命令：跟随 / 守住 / 突击 / 救人 / 自由。
- 队员不抢玩家镜头：默认在玩家侧后 3–6m，进入建筑时自动散开。
- 队员会报点（“二楼窗口”“背后有人”），但不显示全图敌人。

### 5.3 感知与公平性

- 视距 60–80m，受烟雾/掩体遮挡；
- 听觉：脚步 14m、枪声 60m、破门 40m；
- 反应时间 0.25–0.5s，命中率随距离衰减；
- 不预瞄、不穿烟锁头、不在玩家出生点刷；
- 被击中后 1.5s 内优先找掩体/反击，而不是原地站桩。

## 6. HUD / UX

- 左下：生命/护甲；右下：弹药/装备。
- 顶部：目标（A/B/撤离） + 警报等级 + 撤离倒计时。
- 左上：小队状态（3 名队员，倒地/存活/距离）。
- 中央：极简准星、命中反馈、受伤方向。
- 小地图：**只显示已探索区域、目标、队友**，不显示敌人（或只显示最近开枪的模糊方向）。
- 交互提示：门/电脑/救援/破门，按住/点按区分。
- 结算：目标、队员存活、战利品、用时、路线、失败原因。

## 7. 成长与重复可玩

MVP 只做**局内成长**：

- 每局固定装备或简单三选一（步枪/冲锋枪/狙击）；
- 结算给经验，解锁外观/武器变体；
- 不做永久掉落、不做跳蚤市场。

后续可加：

- 3 张 RAID 站点（黑港、边境村、沙漠泵站）；
- 每日任务/情报链；
- 硬核模式：死亡掉落装备；
- 双人/四人联机。

---

## 8. MVP 范围（必须做）

1. 1 张 160×160m 黑港站点，3 条路线，2 个目标，1 个撤离点。
2. 玩家 + 3 AI 队员 vs 12 守军 + 4 QRF。
3. 4 把武器、手雷/烟雾、医疗包、破门点。
4. 巡逻/听声/调查/包抄/增援 AI。
5. 倒地/救援/失败/结算。
6. 极简 HUD、目标提示、撤离倒计时。
7. 60fps @ 1080p 中画质；AI 不长时间卡墙。

### 明确不做（v5 MVP）

- 5v5 竞技匹配、排位、经济；
- 载具、破坏、天气；
- 20+ AI 同屏；
- 开放世界/三张 300m 城镇；
- 复杂人物自定义。

## 9. 验收指标

| 指标 | 目标 |
|---|---|
| 首局理解 | 不看文档，30 秒内知道目标 |
| 单局时长 | 10–15 分钟 |
| 路线使用 | 3 条路线在 10 局内都被走过 |
| 交火节奏 | 前 2 分钟至少 1 次交火；之后每 60–90 秒有压力 |
| AI | 巡逻/调查/包抄可见；10 秒内不卡墙；不全部挤在同一点 |
| 失败可读 | 玩家能说出“为什么输”（全灭/超时/警报） |
| 性能 | 1080p 中画质 ≥60fps；模拟 60 帧 <2ms CPU |
| 重玩 | 结算页提供“换路线再来” |

## 10. 与现有代码的映射

| 现有系统 | v5 处理 |
|---|---|
| `Game` / `Squad` / `AIBrain` | 保留骨架；替换为 RaidDirector + 巡逻/调查/QRF 状态机 |
| `Combat` / `WEAPONS` / `Projectiles` | 保留，调 TTK/弹药/伤害 |
| 倒地/救援/战利品 | 保留，拉长流血时间，限制医疗包 |
| `World` / Rapier / nav | 保留技术底座；地图改为 160m MapSpec |
| 20 人 AI | 降为 3 队友 + 12 守军 + 4 QRF |
| 三张 300m 城镇 | 先只做黑港站点 A；其他地图移出 MVP |
| 程序化建筑 | 替换为 v5 authored GLB 预制体（见 building-kit-v5.md） |
| 占点/毒圈/迫击炮 | 从 MVP 移除或降为可选事件 |

## 11. 风险

1. **AI 巡逻/调查做不好** → 先做灰盒 + 可视化巡逻线，再谈建筑美术。
2. **160m 地图仍可能空** → 用“建筑 + 围墙 + 集装箱”形成连续掩体，不做大片草地。
3. **室内照明/阴影** → 采用 authored 预制体 + 烘焙/顶点色/单盏补光，避免运行时堆灯。
4. **玩家嫌内容少** → 先保证一局好玩，再加第二张站点；不要先铺三张空图。
5. **范围膨胀** → MVP 只做 RAID，不做 PvP/载具/经济。
