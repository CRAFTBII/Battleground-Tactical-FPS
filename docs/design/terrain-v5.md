# v5 自然地形方案（黑港站点 A）

> 结论：**要自然地形，但不要“纯噪声铺满全图”**。  
> 对 160m 的 CQB RAID 图，地形首先是**玩法结构**（海堤、排水渠、土坡、掩体、边界），其次才是视觉起伏。  
> 关联：[玩法](gameplay-v5.md) · [地图设计板](raid-site-a-layout.html) · [建筑规格](building-spec-sheet.md)

## 1. 为什么不能纯 Perlin 噪声

纯 FBM 起伏会带来：

- 门/楼梯/建筑地坪不在同一高度，门槛变成 0.2–0.8m 的随机台阶；
- AI 导航采样到陡坡/沟壑，卡墙、绕路、掉进沟里；
- 长视线被随机土包切断，地图可读性下降；
- 载具/集装箱/道路无法自然贴合；
- 玩家分不清“可走土坡”和“不可走装饰地形”。

正确做法：** authored 地形骨架 + Perlin 细节 + 强掩膜（mask）**。  
先决定哪里是海、哪里是沟、哪里是平台，再用噪声打破“水泥地一样平”的感觉。

## 2. 黑港站点 A 的地形骨架

地图 160×160m，坐标与 [设计板](raid-site-a-layout.html) 一致。

| 区域 | 地形 | 玩法作用 |
|---|---|---|
| **西侧 x 0–18** | 海面/滩涂，水位 −1.2m；x=18 海堤/码头墙 | 边界、视觉纵深、落水惩罚（可选） |
| **西线集装箱场 x 18–65, z 70–140** | 混凝土 apron，抬高 +0.4m；边缘 1:8 坡道 | 集装箱迷宫；比主街高 0.4m，形成轻微高地 |
| **中央 x 65–95, z 30–140** | 平整硬地 0m | 主街长枪线；建筑/道路绝对平 |
| **东线排水渠 x 120–135, z 60–140** | 渠底 −1.8m，混凝土渠壁；z=80/120 两处坡道/梯 | C 线潜行；低洼、出口少、被发现的代价 |
| **北侧撤离 z 0–30** | 2–4m 土堤/防波堤，中央 x 70–90 留切口 | 撤离口易守难攻；守军高位 |
| **南侧插入 z 140–160** | 1–2m 低土堤 + 门洞 | 出生区掩护；不直视撤离点 |
| **开放院区** | 少量 0.8–1.5m 土包/岩石 | 掩体/断视线，不形成随机迷宫 |
| **地图边界** | 3–5m 防波堤/围墙/岩壁 | 物理边界，不做空气墙 |

高度范围：**−2.0m（水/渠底）～ +5.0m（北堤）**。  
可走坡度 ≤20°；20–30° 需要坡道/台阶；>30° 视为不可走（岩壁/挡土墙）。

## 3. 高度场规格

| 项目 | 建议 |
|---|---|
| 范围 | 160×160m |
| 视觉网格 | 1m（160×160 段，约 25k 三角） |
| 碰撞网格 | 1m trimesh 或 Rapier heightfield（80×80 也可） |
| 导航采样 | 2m（与当前 nav 一致），坡度/台阶过滤 |
| 高度格式 | 16-bit PNG（0–65535）+ JSON 元数据 |
| 高度缩放 | `heightScale = 8.0m`（把 0..65535 映射到 −2..+6） |
| 原点 | 地图 (0,0) 对应 PNG 左上角；x 向右，z 向下 |
| 平滑 | 2 次 thermal erosion / 高斯平滑，避免锯齿 |
| 掩膜 | 建筑/道路/据点/出生点外扩 4m 平场；smoothstep 过渡 |

### 3.1 Perlin/FBM 参数

基础噪声只负责“非玩法区”的细节：

```text
baseFrequency = 1 / 65m      // 波长约 65m
octaves       = 5
lacunarity    = 2.0
persistence   = 0.5
amplitude     = 3.2m         // 掩膜前
domainWarp    = 0.15 * (1/65m)  // 轻微扭曲，避免规则感
```

然后用**区域掩膜**压平/塑形：

```text
height = baseNoise * maskPlayable * 0.35
       + handShapedTerrain * maskSkeleton
```

- 建筑/道路/据点/出生点：`maskPlayable = 0`，外扩 4m 平滑；
- 海/渠/堤：用 authored 高度骨架，不被噪声覆盖；
- 开放院区：噪声保留 0.3–0.8m 起伏；
- 边界：向 3–5m 土堤抬升，压住噪声。

### 3.2 建筑/道路平场

所有 `buildings` / `roads` / `capturePoints` / `spawns`  footprint 外扩 4m 内高度 = 该建筑地坪高度（通常 0 或 +0.4m），边缘 6m smoothstep 过渡。  
门/楼梯/台阶仍然由建筑 GLB 负责，不靠地形做台阶。

## 4. 材质与视觉

- 4 层混合：混凝土/沥青、湿沙/滩涂、草/杂草、岩石/碎石。
- 用顶点色或 splat map（1K）按高度/坡度/区域混合；不每米一张贴图。
- 坡度 >30° 自动偏岩石；水边偏湿沙；道路/建筑平场偏混凝土。
- 添加贴花：轮胎印、水洼、裂缝、锈迹、弹坑。
- 放置规则：草/灌木只放在坡度 <15° 且非道路/建筑区；岩石可放在坡地。
- 水体：西侧海面/东侧渠底用简单半透明水面 + 边缘湿痕；MVP 可不做游泳，落水即减速/受伤并回到岸边。

## 5. 与现有 v4 地形代码的关系

当前 `js/world/runtime.js` 的 `_buildTerrain` 是 100×100 的值噪声 + 平场，适合 300m 城镇，但不适合 160m 战术图：

- 网格 3m 太粗，沟渠/坡道会糊；
- 没有 authored 海/渠/堤骨架；
- 平场只按 footprint 外扩，不能表达“高 0.4m 的集装箱 apron”和“−1.8m 的渠底”。

v5 替换为：

1. 读取 `data/maps/raid-site-a.terrain.json`（尺寸/高度缩放/原点/水面高度）；
2. 读取 16-bit 高度 PNG；
3. 构建 1m 视觉网格 + 1m 碰撞 trimesh/heightfield；
4. 建筑/道路按平场高度落地；
5. 导航 2m 采样，标记坡度/水面/不可走；
6. 材质按高度/坡度/区域混合。

## 6. 交付格式（如果你来生成）

建议输出：

```text
data/maps/raid-site-a.terrain.json
data/maps/raid-site-a.heightmap.png
```

`terrain.json`：

```json
{
  "id": "raid-site-a",
  "size": 160,
  "resolution": 161,
  "heightScale": 8.0,
  "heightOffset": -2.0,
  "waterLevel": -1.2,
  "origin": "north-west",
  "seed": 20261106,
  "notes": "16-bit grayscale; x right, z down"
}
```

PNG：161×161 或 321×321，16-bit 灰度；0 = 最低（−2m），65535 = 最高（+6m）。  
如果高度范围不同，改 `heightScale/heightOffset` 即可，不要在代码里写死。

## 7. 验收

- 建筑/道路/据点/出生点平场高度误差 ≤2cm；
- 门/楼梯/台阶不被地形顶穿；
- 可走坡度 ≤20°，AI 不卡沟/不爬陡坡；
- 西侧海/东侧渠/北侧堤在游戏内可辨认；
- 玩家从南门到 A/B 的路线不被随机土包切断；
- 视觉网格 ≤30k 三角，碰撞 ≤15k 三角，1080p 60fps；
- 地形材质/植被不遮挡关键视线。

## 8. 结论

**要自然地形，但只做“有玩法目的的地形”**：

- 海堤/滩涂 = 西侧边界与视觉纵深；
- 排水渠 = C 线潜行与低洼风险；
- 北堤 = 撤离口攻防；
- 集装箱 apron +0.4m = 西线轻微高地；
- 少量土包/岩石 = 掩体，不做随机迷宫。

如果你用 Perlin 生成，请按上面的掩膜和交付格式出高度图；我可以直接接进 Rapier/导航/材质，不需要重写地图。
