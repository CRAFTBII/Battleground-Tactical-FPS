# 门 / 破窗交互规格（v5 设计 + v4 垂直切片）

> 先承认：v5 文档里写了“破窗/开门”，但之前 v4 只有门洞，没有交互。  
> 现在已在一个可玩垂直切片里补上 **E 开门/关门 + E 破窗**，并验证了碰撞开关与通行。

## 1. 当前 v4 已实现

### 1.1 门

- 程序化建筑的正门现在有真实门扇（pivot 在铰链）。
- 初始 **关闭**：门扇视觉 + 独立 cuboid collider 填住门洞。
- 玩家靠近、面向门 ≤2.6m 时 HUD 显示 `[E] 开门`。
- 按 E：门扇绕铰链 90° 打开，移除门 collider；再按 E：关门并补回 collider。
- 门打开后玩家/AI 都能通过；关闭时阻挡。
- 门不会与正面窗框/墙段重叠。

### 1.2 破窗/破口

- 在建筑后墙做 **1.4m × 2.4m** 的封板破口（可理解为封死的后窗/后门）。
- 初始有木板 + 金属插销 + 独立 collider，玩家不能穿过。
- 靠近面向破口 ≤2.6m 时 HUD 显示 `[E] 破窗`。
- 按 E：木板隐藏、collider 移除、产生灰尘粒子与音效；之后玩家可以穿过。
- 破口位置固定在楼梯对侧（`+W*0.2`），避免和楼梯井/楼板冲突。
- 后墙原本的地面窗在破口位置自动取消，避免窗框和破口穿插。

### 1.3 HUD / 输入优先级

E 键优先级：

```
救援倒地队友 > 处决倒地敌人 > 门/破窗 > 地图机制 > 搜刮尸体
```

HUD 在屏幕中下方显示 `[E] 开门 / 关门 / 破窗`，与处决提示不同位置；死亡/倒地/回主菜单时自动隐藏。

### 1.4 代码位置

| 文件 | 内容 |

| `js/world/buildings.js` | 门扇、铰链 pivot、破口封板、独立 collider、交互元数据 |

| `js/combat.js` | E 键优先级、调用交互 |
| `js/game.js` | 10Hz HUD 提示、门动画 tick、reset 隐藏 |
| `index.html` / `css/hud.css` | `#interactHint` |

### 1.5 已验证

- 关闭门：玩家从 z=120 向北停在 z≈116.9（门洞+门扇碰撞）。
- 开门后：同一路径穿过到室内 z≈110.3。
- 关门：collider 重新出现，门扇回正。
- 破口关闭：室内向北停在 z≈108.2。
- 破窗后：穿过到室外 z≈100.2，封板隐藏、collider 移除。
- HUD：靠近关闭门显示 `[E] 开门`；开门后提示 `[E] 关门`。

## 2. v5 目标交互（下一步）

当前 v4 是“按 E 立即开门/破窗”的垂直切片；v5 正式版建议：

### 2.1 门

- **普通门**：E 立即开/关；可被 AI 推开（AI 接触门时自动打开）。
- **锁门**：E 提示“需要撬锁/钥匙卡”；撬锁 3s，失败触发警报。
- **防火门**：只能从一侧打开；另一侧有把手/破窗。
- **双开门/卷帘门**：仓库卷帘门需要按住 E 1.5s 或破门炸药。

### 2.2 破窗/破门

- **破窗**：真实 1.2×1.2 窗洞；按 E **翻越**（0.6s 动画，玩家落到另一侧），不要求破坏整面墙。
- **破门炸药**：对 marked breach 点使用，1.5s 引爆；移除封板并产生爆炸噪音，触发守军调查。
- **普通窗**：不可破，只能射击/观察；玻璃可被子弹击碎（后续）。
- **破口后**：洞口保留，NAV 增加 link，AI 也能通过。

### 2.3 交互表现

- 门：把手转动、门扇缓动 90°、铰链声、门后视线逐渐打开。
- 破窗：木板断裂/玻璃碎裂粒子、灰尘、短促音效；0.4s 后才能穿过。
- HUD：`[E] 开门` / `[E] 关门` / `[E] 破窗` / `[E] 撬锁` / `[E] 放置破门炸药`。
- 交互范围 2.6m；必须面向目标（±60°）；不穿透墙体交互。

### 2.4 AI

- AI 巡逻经过门时自动开门（不破坏）。
- 守军听到破窗/破门声 → 进入 Investigate，去最后已知位置。
- AI 不会穿关闭的门；NAV 在门锚点处有 link，门状态改变后更新可走性。
- 玩家小队 AI 跟随玩家穿门；门关闭时自动开。

## 3. 验收

- [ ] 关闭门能挡玩家/AI/子弹（子弹按材质决定是否穿透）
- [ ] E 开门/关门状态、collider、动画一致
- [ ] 破窗后洞口可通行，NAV/AI 同步
- [ ] HUD 提示只在面向、范围内显示
- [ ] 交互不会与救援/处决/搜刮冲突
- [ ] 门/破口不与楼梯、窗框、楼板穿插
- [ ] 声音可被 AI 听到并触发调查

> 当前垂直切片先证明“能开、能破、能过、能挡”；v5 正式版再把撬锁、翻窗、炸药、AI 开门和声音调查补全。
