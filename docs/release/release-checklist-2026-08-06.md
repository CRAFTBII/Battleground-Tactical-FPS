## 1. 上线前检查项（人工逐项勾选）

### 1.1 构建与启动

- [ ] **离线双击即玩**：直接双击 `index.html`（`file://`），无红条错误、可进菜单、可开始单人战役（three.js 本地化，不依赖网络/CDN；地图为 JS 模块注册，无 fetch JSON）。
- [ ] **联机验证**：`node server.js`（默认 8080）启动无报错；浏览器开 `index.html` → 创建联机房间 → 第二客户端输入房主 IP 加入 → 状态/事件广播正常（Windows 首次放行防火墙）。
- [ ] **回归全绿**：`node test/smoke.js` → 退出码 0，末尾「无头冒烟测试全部通过」。
- [ ] **服务端协议回归**：另起 `node server.js` 后跑 `node test/server-test.js` → 通过（握手/建房/加入/state 路由/事件广播）。

### 1.2 地图（本次里程碑核心）

- [ ] **地图选择菜单**：主菜单显示 3 个地图按钮（城郊战场 / 夜港工业区 / 荒漠前哨），点击即时背景预览，开始单人战役使用所选地图。
- [ ] **URL 参数 `?map=`**：`index.html?map=port` 直接进入夜港工业区；`?map=desert` 进入荒漠前哨；非法/缺省回退默认图（suburb）。
- [ ] **三图可玩**：suburb(300) / port(260) / desert(340) 均可开局、据点 A/B/C 可占、出生点无堵塞、A* 60/60 路径全通。
- [ ] **`?detail=off` 逃生舱**：`index.html?detail=off` 后三图精修（暗腔/雨落管/AC 机组/檐口/分缝）全部关闭，碰撞/平台数量不变（141/213/213），低端机可降 LOD。
- [ ] **`?cvd=1` 色盲模式**：`index.html?cvd=1` 后队伍色切换蓝-橙安全色相轴，红蓝可辨。

### 1.3 稳定性与观感

- [ ] **浏览器控制台无红色报错**：三图各加载一次，控制台无 `console.error` / 未捕获异常（GLB 未启用时的 `console.log` 回退提示属正常）。
- [ ] **换图无串图残留**：菜单连续切换三图，场景不残留旧图对象、控制台无泄漏报错。
- [ ] **性能抽测**：三图 300 帧战斗模拟平均 <1ms/帧、最坏帧 <80ms（参考：平均 0.10~0.58ms）。
