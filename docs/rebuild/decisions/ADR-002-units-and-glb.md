# ADR-002：米制、Y-up 与显式 GLB 节点角色

- 状态：Accepted
- 日期：2026-11-01

## 决策
1 世界单位 = 1 米，Y-up；建筑局部原点为 footprint 中心地面点。默认实例缩放为 1。每种模型按 Catalog 目标尺寸单独修复，不允许全局资产倍率。

每个 GLB 显式分离 VIS、COL、NAV、ANCHOR 节点角色，角色写入 glTF extras。门洞必须在 COL 几何中真实留空，楼板和楼梯必须有 NAV 语义。

## 原因
现有导出资产尺寸、楼层标高、原点与碰撞代理不统一。全局放大不能修复楼层比例、门洞、台阶和地图间距。

## 后果
现有派生 GLB 不直接晋级 v4；必须在 Blender 修复几何、原点、轴向、楼层和代理后重导出。
