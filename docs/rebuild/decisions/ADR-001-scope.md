# ADR-001：重建地图子系统，保留游戏主体

- 状态：Accepted
- 日期：2026-11-01

## 决策
重建地图、资产、碰撞、导航、出生和地图 QA；保留角色、武器、战斗规则、AI 战术、网络、UI、音效和通用机制。

## 原因
旧 World 把地图构建、碰撞和导航耦合在一个大模块，地图数据又分散在 JS、TownGen 和 importer 元数据中。尺寸缩水、穿墙和空气墙无法通过局部补丁稳定解决。

## 后果
新 runtime 必须提供 WorldCompat，按模块迁移旧调用点；不得把 game.js / ai.js / combat.js 全部推倒重写。v4 完成前此分支不可运行。
