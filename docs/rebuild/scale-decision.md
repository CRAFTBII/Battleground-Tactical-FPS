- 门净宽 **≥1.3m**（0.7 + 0.6 余量；窄门最低 1.2m）

- 门净高 **≥2.4m**（2.0 + 0.4 余量；上限 2.2 角色也能过）
- 房间净高 **≥3.0m**（2.0 + 1.0；避免顶头）

## 3. 街道/街区

- 主街净宽 14m，次街 10m，巷道 6m（≥2 个胶囊交错）。
- 人行道 2m；门到路缘 ≥3m。
- 街区 60~90m 模数；建筑间距 ≥3.5m。
- 掩体高度 1.0~1.6m；可翻越边界 ≤2.4m；超过 2.4m 必须有门/梯/缺口。

## 4. 相机与第一人称

- 相机眼高 **1.85m**；眼高由 profile 提供，不能写死。
- 第一人称武器锚点：右臂基座约 1.60m；枪口前向 0.4~0.75m。
- 开镜、枪口火光、弹道起点、投掷点都从 `profile.anchors` 取。
