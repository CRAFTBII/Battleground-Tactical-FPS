# v4 尺度决策：以 2.5m 角色 / 2.3m 相机为基准

> 状态：Accepted（v4）  
> 输入：用户明确“人物模型最高按 2.5m 算，别忽略相机位置”；当前角色相机旧值 1.7m、碰撞体高 1.8m。  
> 结论：旧 1.7m 尺度整体作废；v4 建筑、门洞、楼层、街道、掩体全部按 **2.5m 角色**重定。

## 1. 角色契约

| 项 | 值 | 说明 |
|---|---:|---|
| 设计身高 H | **2.50 m** | 所有角色 profile 不得超过 |
| 相机眼高 E | **2.30 m** | 0.92H；相机必须来自 profile，不能写死 1.7 |
| 胶囊半径 R | **0.45 m** | 胶囊直径 0.90 |
| 胶囊总高 | **2.50 m** | 圆柱段半高 = (2.5 - 0.9)/2 = 0.80 |
| 台阶高 | **0.55 m** | 角色 controller 单步上限 |
| 相机 near/far/FOV | 0.1 / 1200 / 70 | profile 可覆盖 |
| 武器/枪口锚点 | eye 2.30；weapon 1.95；muzzle 1.95+0.45 | profile.anchors，随角色缩放 |
| 角色模型缩放 | profile.scale = height / modelHeight | 当前占位 1.9m → 1.3158 |

玩家胶囊直径 0.9m，因此：

- 门净宽 **≥1.6m**（0.9 + 0.7 余量；窄门最低 1.4m 只允许单人侧身）
- 走廊净宽 **≥2.2m**（两人交错）
- 门净高 **≥3.0m**（2.5 + 0.5 余量）
- 房间净高 **≥3.8m**（2.5 + 1.3；避免“顶头”）

## 3. 街道/街区

- 主街净宽 16m，次街 12m，巷道 8m（≥2 个胶囊交错）。
- 人行道 2.5m；门到路缘 ≥3m，避免门被掩体堵死。
- 街区尺寸按 60~90m 模数；建筑间距 ≥4m（角色+门扇+碰撞余量）。
- 掩体间距/高度：沙袋 1.2~1.6m，矮墙 1.2m，可翻越边界 ≤2.8m；超过 2.8m 必须有门/梯/缺口。

## 4. 相机与第一人称

- 相机眼高 **2.30m**；当前 1.7m 直接废弃。
- 第一人称武器锚点：右臂/枪身基座约 1.95m；枪口沿前向 0.45~0.8m；具体由 `profile.anchors` 给出。
- 开镜/瞄准、枪口火光、弹道起点、手雷投掷点必须以锚点为准，不能再用写死坐标。
- 角色模型 1.9m 占位会按 `profile.scale=1.3158` 放大到 2.5m；相机在 2.3m，正好在头部下方，不会“穿头”。

## 5. 对现有资产的影响

- 所有源模型当前层高约 3.0~3.2m，**不够 2.5m 角色 + 3.0m 门**；必须 Blender 修复/补层，不能只乘全局倍率。
- Apartment 只有 2 层；目标 5 层 22m，需要补建模。
- Base 目标 16m（2 层 4.8 + 屋顶）；Estate 10m（2×4.4 + 屋顶）。
- 所有 COL/NAV/ANCHOR 必须与修复后的几何一起导出；旧派生 GLB 不用。

## 6. 验收数值（P0）

- 角色胶囊 2.5m/0.9m 直径，能通过所有门；不能通过窗/墙。
- 门净高 ≥3.0m、净宽 ≥1.6m；走廊 ≥2.2m；房间净高 ≥3.8m。
- 楼梯单级 ≤0.55m；平台/楼板支撑稳定；无 0.1m 以上台阶突变。
- 相机眼高 2.3m；不穿天花板/门楣；开镜和枪口锚点与 profile 一致。
- 视觉墙/沙包与 COL 射线误差 ≤0.03m；无穿墙、无空气墙。
