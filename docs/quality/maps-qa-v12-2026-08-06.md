# 判定：FAIL（阻塞项见下）

| 级别 | 项 | 说明 |
|------|----|------|
| **BLOCKER（必修）** | desert 水塔回血 ≈ **150HP/s**（设计 5HP/s） | `mechanics.js _ssSim` 水塔回血块**无 2Hz 节流**：每帧 `heal*0.5=2.5`，60fps=150HP/s（实测 1s 内 40→100 触顶）。设计 §3.2 明确 5HP/s 上限 100 → 塔圈=无敌回血区，打破「水塔续航但可被反抢」平衡。与伤害块（有 `stormTickT` 节流）不对称。smoke §4.11② 仅断言「hp 增加」故漏检。 |
| **MAJOR（设计功能缺失）** | port 抢修（repair）路径未实现 | 设计 §2.2 核心反制：断电期内任意一方到任一配电箱按 E → **立即恢复供电** + 抢修冷却 45s。实现 `dispatch('interact')` 在 `power===false` 时**直接 return false**（mechanics.js:483），断电后无任何方式提前恢复，只能等 45s 自动到点。设计原则 4「反制对称」缺失一半。 |
| **MAJOR（数值/玩法与规格不符）** | suburb 炮击警示圈=28m 整区 + 落点固定 center(150,150) | 设计 §4.2：警示圈半径=**爆炸半径 8m**、位置在 zone 内**随机**。实现：警示环 `RingGeometry(zone.r-0.6, zone.r)`=28m，落弹 `areaDamage(center, radius 8)`。→ 红圈 28m 但伤害仅中心 8m，玩家被红圈误导；落点从不随机，躲炮变成「别站广场中心」而非「看 8m 圈落哪」。 |

> 说明：其余偏差归 CONCERNS（非阻塞风险），见 §5。质量门为建议性门控，最终放行由用户决定。

## 4. 证据摘录（关键代码行）

- 水塔回血无节流：`js/mechanics.js:323-337`（`_ssSim` 水塔块每帧执行，`this._heal(u, tw.heal * 0.5)`；仅伤害块用 `s.stormTickT` 节流）→ 实测 150HP/s
- 抢修缺失：`js/mechanics.js:483` `if (!s || s.power === false) return false;` → 断电期内 E 无任何恢复路径
- 炮击警示=整区：`js/mechanics.js:428` `s.arty.warn = { x: z.x, z: z.z, r: z.r }`（zone.r=28）+ `:418` `areaDamage(center, radius 8)`；`RingGeometry(z.r-0.6, z.r)` 28m
- 掩体不挡爆炸：`js/game.js:193-201` `Game.areaDamage` 仅距离衰减，无 `rayBlocked`
- AI 惩罚无条件：`js/ai.js:182` `if (Mechanics.stormActive()) acc *= 0.5;`（无 `d>20` 判定）
- 庇护仅墙边：`js/mechanics.js:339-343` `_inShelter` 检查碰撞体外扩 2m（无「建筑内部」概念、无水塔圈）
- 断电数值：`js/mechanics.js:488` `s.offT = panel.cd || 45`（=45s，设计 30s）、`panel.coolT = (panel.cd || 45) + 8`（=53s，设计 45s）
- 曝光 ping 位置：`js/mechanics.js:206` `l.x + dirX * d2 / l.range * 4`（用**平方距离** d2 → 30m 处 ping 偏移 80m，小地图红点落点偏差，纯 cosmetic）

## 6. 结论与建议

- **工程自测可信**：smoke RC=0、密度三图全过、断言真实执行；建筑/密度/渲染部分**无问题**。
- **机制「能跑但不达设计契约」**：三套机制的**主功能链路全部工作**（曝露/断电/雾/灼伤/回血/空投/炮击伤害/联机同步），但存在 1 个平衡级 bug（水塔回血 150HP/s）、2 个设计功能缺失（抢修、炮击警示圈/随机落点）、6+ 项数值/庇护/阈值偏差。
- **放行建议**：desert 水塔回血为阻塞项（建议先修：回血块补 2Hz 节流，或将 `tw.heal` 语义改为「每秒」按帧折算）；port 抢修与 suburb 炮击警示圈为设计契约缺口，需工程补实现或设计侧书面降级后再发。其余 [PLAYTEST] 项可在首轮内测收敛。
- **后续**：`[PLAYTEST]` 标注数值（§5 表）建议按首轮实测收敛一次；修复后补回归断言（水塔速率阈值、抢修路径、警示圈半径、20m 阈值、建筑内部庇护）。
