# 质量门控报告 · v2.9 地图扩大 + 三地带据点

- **日期**：2026-08-07
- **版本**：[1.10.6]
- **需求来源**：用户「每一个地图只设置三个据点(地带),且扩大地图范围(你不用考虑建筑)」

## 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 地图扩大倍数 | ×1.5（suburb 300→450 / desert 340→510 / port 260→390） | 起步值 [PLACEHOLDER]，playtest 后可再调；建筑坐标不动（用户明示），外围空地 |
| 扩大配套 | zone r/atSec、阴影 extent/far 等比 ×1.5；findPath 上限自适应 n×n+10000 | 不配套则开局出圈掉血 / 阴影缺失 / 大图寻路提前放弃（3 类真实故障全被测试抓到） |
| 据点形态 | 3 条带地带（z 三等分），判定用条带区域非圆 | 满足"3 个据点 + 不是圆 + 覆盖整图"；多队占领机制复用 |
| 据点 x 位置 | 地带内出生点质心（活动区） | **关键修复**：固定地图中心 x 在 desert 放大后穿建筑带，A 地带 8 条 A* 失败（据点不可达） |

## 实现摘要

- **三图**：size ×1.5 + zone（r/atSec ×1.5）+ 阴影（extent/far ×1.5）；suburb arty 半径 r:28 未被误伤（正则只匹配带逗号的 r）
- **world.js**：`gridCaps`(9 网格) → `bandsCaps`(3 条带)；buildCapturePoints/Game.initCaps 保留 band 标志；findPath 探索上限自适应
- **game.js**：updateCaps 支持 band 判定（|u.z−c.z|≤r 即在该地带）
- 多队占领、CONTROL 控制时长、吃鸡终局机制不变（地带只是判定几何）
