## 1. 概论

| 字段 | 值 |
|------|----|
| 名称 | 荒漠前哨（Desert） |
| 主题 | 暖橙日照 · 沙漠补给站 · 开阔 |
| 尺寸 | `size:340`（城郊 300，大 40m） |
| 一句话定位 | 开阔中庭、绵延沙丘与稀疏残骸，据点相隔近百米——每一次穿越空地都是一次赌博 |
| 设计支柱 | ① 长视线驱动的"暴露焦虑" ② 沙丘即掩体的地形博弈 ③ 守点 + 车队式推进的慢节奏 |

**美学基调（MDA）**：通过暖橙远雾（fog `near:120`/`far:430`）+ 高强日照（sun `intensity:1.65`）保留长视线，同时 `terrain.amp:7.0` 制造 8m 级沙丘——掩体不是建筑给的，是**地形本身给的**。玩家在"看得远、但无处躲"的张力里被迫组织推进。

## 3. 据点布局与 rationale

统一 A/B/C 三点占领玩法：

| 据点 | 坐标 | 落位 rationale |
|------|------|---------------|
| **A** | (170,170) | 地图几何中心＝前哨中庭。四面**开阔**，是三图里最难守的 A 点；仅依赖 D1 主堡与 D11/D12 外沿掩体组提供最后一段掩护。 |
| **B** | (96,118) | 蓝侧侧向补给路（x 55~205）上的补给站，对称偏移 (±74,±52)。**D3 观察塔楼(16.6m)** 提供制空视野。 |
| **C** | (244,222) | 红侧侧向补给路（x 135~285）上的检查站，与 B 对称。**D5 指挥所** 掩护。 |

- 三点两两距离 ≈90m（B↔C 181m）——全图最长轮转距离，单兵转点耗时长，逼出"守点 + 车队式推进"打法，节奏慢。
- 建筑彼此远离（间距 60–90m），建筑之间是需冲锋通过的**开阔沙地**——这是"慢节奏"的结构性来源。
- A* 校验：全部出生点 → 全部据点连通；沙丘 `mounds` 全部避开 `flatten` 矩形，无断崖。

## 4. 垂直度设计

本图**刻意压低人工垂直度**，把"高度"交还给地形：

1. **唯一可攀屋顶**：D1 中央前哨主堡（proc, 28×20, h7, `rooftop:{side:'west'}`）是全镇唯一可登顶建筑，7m 屋顶俯瞰 A 中庭——稀缺资源，争夺价值高。
2. **制空来自塔楼而非可攀屋顶**：D3(16.6m) / D5(16.6m) 为 model 公寓改造的瞭望/指挥塔，提供视野但不提供登顶路径（model 屋顶无坡道）。
3. **8m 级沙丘**承担主要"高地"功能：西北/东南两大沙丘（peak 3.2, scale 2.5 → ≈8m）成为天然制高点与侧翼绕后通道。

> ⚠️ 同港区约束：proc `rooftop.side` 必须用 `'west'`（D1 已用，探针验证坡道可达）。

## 4.5 专属机制：沙暴 + 水塔（v1.2）

> 完整规格见 `design/maps/mechanics.md` §3；数据在 `desert.js` 的 `mechanics` 字段。

- **周期沙暴**：`cycle { stormSec:30, calmSec:90 }`，首爆在第 90s。风暴期雾插值到 `near:15/far:70`（视野骤降）、AI 对 20m 外目标命中 ×0.5、暴露者每秒受 `exposeDmg:4` 伤害。
- **水塔（D13 tower, 152,132 r10）**：可占领回血设施（复用据点占领逻辑，单点、不产分），占领方圈内每秒 +5 HP；敌方可反抢。
- **与据点玩法关系**：沙暴压缩节奏（风暴期转近身接触战），水塔提供续航（占点损耗后回血再回点）——让"慢节奏"图在风暴期有高潮、在平静期有资源争夺。

### 4.6 缩圈（v1.3）

> 完整规格见 `design/maps/zone-br.md`；数据在 `desert.js` 的 `zone` 字段。

- **圈心偏蓝侧 (110,140)**：终局（r44）覆盖 B 点(96,118) 附近 → 红方需长途奔袭，蓝方拥主场；与 port 偏红对称，避免两图终局同侧。
- **5 阶段**：r 315→195→126→82→44（首缩 90s，与沙暴首爆同刻），圈外伤害 1→3→6→10→15 HP/s。
- **与沙暴共存（重点）**：伤害**可叠加**——圈外 + 风暴暴露 = `dmgPerSec + exposeDmg`（预期戏剧性时刻）；沙暴 shelter（建筑/水塔圈）**不豁免缩圈伤害**（躲建筑躲不了圈）；水塔回血圈外仍生效但 5 HP/s < P3 后 10~15 HP/s，不能赖圈外——水塔从"续航支点"升级为"圈外高风险续航"。

### 4.7 桥梯（v1.3）

> 数据在 `desert.js` `buildings` 数组末尾（Bridge1/S1/S2）。

- **Bridge1** 跨纵主道（x 155~185 / 桥面 6m）：架在 B 点(96,118) 与中央中庭之间的开阔沙地上，给长视线图一个**二层观察/压制位**（与"低垂直度"定位互补：沙丘 8m + 天桥 6m 都不压过 D1 主堡 7m）。
- **2 座 stairs**（顶 6m 接桥面）：玩家专属登顶；AI 绕行桥下。
- 桥面 collider overhead 分流与移动碰撞 y 判定 = 工程联调项（见 zone-br.md §7.3）。

### 4.8 地标：前哨基地 base + 巨塔 megatower（v1.4）

> 数据在 `desert.js` `buildings` 数组末尾（BA1/MG1）；规格见 `design/maps/ai-tactics.md` §9 联调项。

- **BA1 前哨基地**：`type:'model', key:'base', 角点 (60,160) · 24×18×8`，tint 土黄 `0xd8c49a`（desert 暖色）。**蓝方推进走廊中段**——蓝方出生区 (0~80,0~80) 出门北上、B 点 (96,118) 之前的第一个"可进可守"建筑，把"开阔沙地直冲"拆成"先占基地 → 再打 B"的两段式推进。
- **MG1 巨塔**：`type:'model', key:'megatower', 角点 (250,70) · 20×20×28`，tint 沙棕 `0xc9b082`。东北制空锚点，与西北沙丘 (60,250) 形成对角天际线。

#### MG1「可上？」设计取舍（用户拍板项）

**结论：v1.4 不可上（纯视觉制空 + 底部可通行），登顶玩法记 backlog。**

理由：
1. **引擎能力硬限**：`zone-architecture.md` §9 backlog #1 明确——当前移动碰撞无"站 collider 顶部不被推出"的 y 顶面支持（AABB 顶面分离轴未实现）。即使 BuildingLib 为 megatower 注册平台（platforms），玩家跳跃到平台上也会被碰撞推出，登顶体验是坏的。
2. **定位自洽**：desert 是"低垂直度"图（D1 主堡 7m 是唯一可攀屋顶，刻意压人工高度）。若巨塔可上（28m 制空），会一举打破 desert 的"长视线 + 低高度"核心张力，变成"占塔即控场"——与支柱 ②「沙丘即掩体的地形博弈」冲突。
3. **占位盒阶段的地图安全**：未注册前 megatower 是实心高盒（20×20×28），若可上则会成为 28m 空中掩体+狙击位，占位阶段即失控。

**v1.4 落地形态**：megatower 做**视觉天际线锚点**（玩家看得到、可作为方向参照），工程注册真模型时做成**腿式结构**（底部四腿之间可通行，复用 tower 类型范式）——既保留"巨塔压迫感"，又不堵地面；登顶玩法等 y 碰撞落地后以 P2 形态追加（可做成"塔内螺旋楼梯 + 顶部平台"）。

- **flattenPad**：`[72,169,24,18]`（BA1）、`[260,80,20,20]`（MG1）已追加，两处地基压平（MG1 压在东南大沙丘 (280,90) 影响半径内，flattenPad 保证塔基平整）。
- **BuildingLib 新类型 key:'base'/'megatower'**：工程注册前 → `placeModelBuilding` 回退占位盒（碰撞=w/d/h，安全）；GLB 插槽 `models/out/battle_base.glb` / `battle_megatower.glb` 离线休眠（ADR-003）。
- **A* 自证**：探针 PASS——desert 18 栋、纵/横主道端到端可通行、20 出生点 × 3 据点双向 120/120 全连通、出生点零重叠。

### 4.9 AI 战术对接（v1.4）

> 完整规格见 `design/maps/ai-tactics.md`；desert 专属激活：**战术①沙暴庇护**。

- **沙暴庇护（ai-tactics §2）**：风暴期暴露的 AI → 12m 内找建筑 footprint / 水塔圈庇护；无庇护 → 优先进圈（zoneDest）/最近掩体。风暴不再只惩罚玩家——AI 也会"躲沙暴"，风暴期 AI 从开阔地消失（进建筑），玩家在风暴中的推进压力被 AI 侧的行为补回一部分戏剧性（AI 在建筑里等风暴，玩家进楼 = 遭遇战）。
- **水塔回血联动**：沙暴庇护优先选水塔圈（_inShelter 已含水塔圈）→ AI 会在风暴期扎堆水塔 → 水塔争夺战升级（占塔方在风暴期同时获得回血 + 队友集结）。
- 其余战术（探照灯避光跨图通用但 desert 无灯自动跳过 / 缩圈边打边退 / 烟雾 / 护甲医疗 / 残血优先 / 统一提难）为跨图通用，desert 亦生效。

## 5. 掩体密度与视线控制

- **掩体数组 26 处**，全部**低矮（1.0–1.5m）**：只够蹲守对枪，**不切断长视线**——长视线是本图核心张力，刻意保留。
- 主干道沿线每 35–50m 布一处"跳岛"（混凝土残墙/箱/箱组），保证冲锋有落脚点，但**不构成连续掩体链**（给对手留出"被打的窗口"）。
- 据点圈以环形沙袋 + 四角路障围合，圈内空旷；出生区前沿各 2 处低矮混凝土掩体。
- 废墟（3 片 rubble）散布开阔区，给空旷地形一点战术纹理与近身掩体，但不改变大局长视线。

## 7. 与「城郊战场」的差异化点

| 维度 | 城郊战场 | 荒漠前哨 |
|------|---------|---------|
| 尺寸 | 300 | **340（更大）** |
| 街道 | 26m 主街 | 18m 主道 + 稀疏土路（无标线） |
| 主题色 | 昼间暖绿 | **暖橙日照** |
| 垂直度 | 基本平房 + 塔楼点缀 | **仅 1 处可攀屋顶（D1），制空靠塔楼** |
| 掩体 | 中（22 处） | **26 处但极低矮、不切视线** |
| 视线 | 中等起伏切断 | **长视线保留（沙丘提供天然遮蔽）** |
| 节奏 | 中 | **慢（据点距 90m、建筑远离）** |
| 地形 | amp 4.4 | **amp 7.0 大沙丘（地形即掩体）** |
| 纹理 | brick/grass/asphalt | **无 'sand' 键 → 用 'sandbag'+terrain 顶点色**（见 §8） |

复用部分：建筑词汇与体量沿用城郊；据点/出生点契约完全沿用；程序化纹理键同套（本图多用 `sandbag`/`concrete`）。

## 8. 已知 Schema / 引擎约束（给工程/美术的备忘）

1. **GLB 插槽已接线但整体休眠**（见 §6）：proc 钩子已由工程 T4 补齐（不再静默忽略）；但 `index.html` 无 GLTFLoader → `GLBSlots.enabled()` 恒 false，全部走程序化。启用真 GLB 需产品侧 ADR（构建/importmap）。
2. **`rooftop.side` 必须 `'west'`**（详见 §4）。
3. **坐标语义**：model 建筑 `x/z` = 西南角、`ry` 不旋转碰撞盒（本图一律 `ry:0`）；proc `x/z` = 中心且 `h === floors*floorH`（D1 7=2×3.5、D4/D6 4.5=1×4.5，已校验通过）。
4. **纹理键无 `'sand'`**：`Tex.get` 仅含 brick/concrete/grass/asphalt/sandbag/metal/floor/roof。本图以 `'sandbag'`(#7a6a4a 沙黄) 铺土路与沙袋工事、`'concrete'` 作建筑主墙，**沙地颜色由 `terrain.colors` 顶点色直接给出**（不依赖纹理键）。如需更地道沙纹，建议美术在 T3 评估是否新增 `sand` 纹理 maker。
5. 沙丘 `mounds` 的 `peak*falloff` 为影响半径、`peak*scale` 为近似峰高，调参时确保不侵入任何 `flatten` 矩形（已校验无断崖）。
