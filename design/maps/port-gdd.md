## 1. 概论

| 字段 | 值 |
|------|----|
| 名称 | 夜港工业区（Port） |
| 主题 | 冷蓝夜景 · 集装箱码头 · 工业 |
| 尺寸 | `size:260`（城郊 300，小 40m） |
| 一句话定位 | 窄街密掩体、三处可攀屋顶制高点，视线被厂房与货柜切成碎片，遭遇战一触即发 |
| 设计支柱 | ① 高垂直度带来的"俯瞰压迫" ② 短交战距离下的高频遭遇 ③ 制高点决定转线权 |

**美学基调（MDA）**：通过冷蓝近雾（fog `near:40`/`far:200`）把玩家感知的交战距离压到 40–200m 以内，配合高强度人工照明（码头灯柱 14 根），在"看得清近处、看不穿远处"的张力里制造伏击快感。

## 3. 据点布局与 rationale

统一 A/B/C 三点占领玩法（与城郊、荒漠完全一致，差异只在位置/垂直度/节奏）：

| 据点 | 坐标 | 落位 rationale |
|------|------|---------------|
| **A** | (130,130) | 地图几何中心＝中央装卸场。四面被 B3/B4/B5/B6 四个仓库/办公楼夹住，进入即贴脸，货柜组（B11/B12 + A 角金属箱）制造进点必经的短掩体链。 |
| **B** | (74,96) | 蓝侧次街十字口，关于中心点 (130,130) 对称偏移 (±56,±34)。正上方 **西泵房屋顶 B7** 可俯瞰，占此点即占制空。 |
| **C** | (186,164) | 红侧次街十字口，与 B 对称。正上方 **东泵房屋顶 B8** 俯瞰。 |

- 三点两两距离 ≈66m（B↔C 131m）——比城郊更短，意味着单兵/小队转点耗时低，交火频率高，节奏快。
- A 居中、B/C 分属两侧，保证任一队从出生点出发都有一条"主街 + 次街"的最短进点路径（A* 校验：全部出生点 → 全部据点连通）。

## 4. 垂直度设计

本图是三图中**垂直度最高**的一张，靠两层手段建立：

1. **真·可攀屋顶（proc + rooftop）**：B1 主库(6m) / B7 西泵房(6m) / B8 东泵房(6m) 三栋 proc 建筑带 `rooftop:{side:'west'}`，生成"站立屋顶平台 + 西侧坡道"。屋顶是 6m 全图制高点，可俯瞰 A 中庭与 B/C 据点，构成核心战术资源。
2. **纯遮挡地标**：B2 塔吊控制楼为三层 proc（h:10.5），本身无坡道入口，作为"切断东西向长视线的巨型掩体"存在，配合 B5/B6 两座 16.6m 办公楼，把中央区切割成多个垂直错落的战斗盒。

> ⚠️ 引擎约束：proc 建筑的 `rooftop.side` **必须用 `'west'`**。引擎实现里 `'east'` 的坡道是"背离建筑向外爬升"，坡道顶端离屋檐约 4m、上不去。本图三处屋顶已统一为 west（并经无头探针验证坡道顶端与同高屋顶平台落差 ≤1.5m、可衔接）。

## 4.5 专属机制：探照灯 + 断电（v1.2）

> 完整规格见 `design/maps/mechanics.md` §2；数据在 `port.js` 的 `mechanics` 字段。

- **4 盏巡逻探照灯**架在制高点（L1 主库顶 / L2 西泵房顶 / L3 东泵房顶 / L4 控制楼顶），以 `yawDeg ± sweep` 往复摆动扫描。
- **被扫到 = 曝露**：小地图红点 + HUD 警示 + 轮廓描边；离锥后 3s 衰减。
- **配电箱 2 个**（蓝侧 66,88 / 红侧 194,158）按 E 断电 → 全灯熄灭 30s，夜战优势（进攻 A/B/C 黄金窗口）；对方可抢修点灯（抢修冷却 45s）。
- **与据点玩法强绑定**：L1/L4 覆盖 A 中庭与主街交叉 → 占 A/过主街高频曝露；断电 = 全员冲点剧本，抢修 = 防守反击剧本。

### 4.6 缩圈（v1.3）

> 完整规格见 `design/maps/zone-br.md`；数据在 `port.js` 的 `zone` 字段。

- **圈心偏红侧 (165,150)**：终局（r32）覆盖 C 点(186,164) 附近 → 蓝方需长途奔袭，红方拥主场；与 port"快节奏偏置压迫"叙事一致。
- **5 阶段**：r 230→143→92→60→32（首缩 90s），圈外伤害 1→3→6→10→15 HP/s；warnSec 5 警示 + 2s 收缩。
- **与探照灯共存**：缩圈独立运行、不豁免——灯扫 + 圈外 = 双压；断电只影响光照不影响圈。
- **新增博弈**：圈外空投/战利品盒 = 高风险高回报（想吃鸡就要冒毒圈风险去舔）。

### 4.7 桥梯（v1.3）

> 数据在 `port.js` `buildings` 数组末尾（Bridge1/S1/S2/Bridge2/S4/S5）；N10/N14 为桥梯让位（§6）。

- **Bridge1** 跨纵主街北段（x 115~145 / 桥面 6m）：连接主街东西两侧的**第二层街道**——玩家从 S1/S2 台阶登顶，俯瞰北段主街与 B 点走廊。
- **Bridge2** 跨东次街（x 171~201 / 桥面 6m）：连接装卸场与东区，俯瞰进 C 走廊。
- **4 座 stairs**（顶 6m 与桥面同高、桥端无缝衔接）：玩家专属竖向通路；AI 2D 导航不爬台阶（绕行桥下地面）。
- **桥面 collider 需工程 overhead 分流**（见 zone-br.md §7.3）：分流后桥下地面可通行、桥面挡子弹；未分流时 AI/玩家绕开桥下（A* 探针仍全绿，仅体验降级）。
- 可攀登性（跳上台阶）依赖工程移动碰撞 y 判定（站在平台顶部不被推出），[PLAYTEST] 项。

### 4.8 地标：炼油厂 refinery（v1.4）

> 数据在 `port.js` `buildings` 数组末尾（REF1）；规格见 `design/maps/ai-tactics.md` §9 联调项。

- **REF1 炼油厂**：`type:'model', key:'refinery', 角点 (186,3) · 20×14×12`，tint 冷灰蓝 `0x7d8a94`（port 夜景工业）。
- **位置 rationale**：红侧北缘工业锚点——红方出生区 (190~260,190~260) 出门北上即见，蓝方从中场可遥望。它是"红方纵深 + 蓝方绕后目标"的双向地标：贴近东次街延长线，作为绕后 A/C 的视觉参考；不堵主街（纵主街 x[123,137] 东侧 49m）。
- **flattenPad**：`[196, 10, 20, 14]`（中心）已追加，炼油区地基压平。
- **BuildingLib 新类型 key:'refinery'**：工程注册前 → `placeModelBuilding` 回退占位盒（碰撞=w/d/h 20×14×12，安全）；GLB 插槽 `models/out/battle_refinery.glb` 离线休眠（ADR-003）。
- **A* 自证**：探针 PASS——port 33 栋、纵/横主街端到端可通行、20 出生点 × 3 据点双向 120/120 全连通、出生点零重叠。

### 4.9 AI 战术对接（v1.4）

> 完整规格见 `design/maps/ai-tactics.md`；port 专属激活：**战术②探照灯避光 + 断电推进**。

- **探照灯避光（ai-tactics §3）**：AI 被曝露连续 >2s → 移到光锥外；被照不再是"白送红点"，AI 会自救 → 玩家利用探照灯"定点照 AI"的战术仍有效但窗口缩短（灯照 AI → AI 撤出 → 玩家趁机推进或换位）。
- **断电推进（ai-tactics §3）**：断电窗口（power=false）→ AI 攻击欲望 +20%（行为推进：横移减半 / 手雷窗口放宽 / 逼近），**不改命中/射速/移速**——断电期玩家夜战优势被 AI 进攻性部分抵消，逼玩家"断电后速攻而非慢摸"。
- 其余战术（缩圈边打边退 / 烟雾 / 护甲医疗 / 残血优先 / 统一提难）为跨图通用，port 亦生效。

## 5. 掩体密度与视线控制

- **掩体数组 36 处**，其中：
  - 金属集装箱（6×2.6×2.5）沿主/次街每 ~30m 一处，专门**切断街道长视线**——禁止出现 100m 直通走廊。
  - 沙袋/路障（sandline/barrier）围绕 A/B/C 据点外沿成环，支撑据点贴脸对枪，但圈内保持空旷以免占点卡视野。
  - 出生区前沿各 2 处低矮混凝土掩体，给出门第一秒的掩护。
- 掩体**不切断全局转线**：A* 校验确认所有出生点仍能抵达所有据点（集装箱只切视线、不切路径）。

## 7. 与「城郊战场」的差异化点

| 维度 | 城郊战场 | 夜港工业区 |
|------|---------|-----------|
| 尺寸 | 300 | **260（更小）** |
| 街道 | 26m 主街 | **14m 主街 / 10m 次街（更窄）** |
| 主题色 | 昼间暖绿 | **冷蓝夜景** |
| 垂直度 | 基本平房 + 塔楼点缀 | **3 处可攀屋顶 + 10.5m 控制楼** |
| 掩体 | 中（22 处） | **36 处、密度 ~2.3 倍** |
| 视线 | 中等起伏切断 | **集装箱高频切视线 + 近雾压缩** |
| 节奏 | 中 | **快（据点距 66m、转点快）** |
| 地形 | amp 4.4 起伏 | **amp 1.6 硬化地坪（走位不被地形干扰）** |

复用部分：建筑词汇（warehouse/apartment/house/watchtower/cover）与体量与城郊一致；据点/出生点契约（3 点 + 对角 10×2 出生）完全沿用；程序化纹理键（asphalt/metal/concrete/sandbag）同套。

## 8. 已知 Schema / 引擎约束（给工程/美术的备忘）

1. **GLB 插槽已接线但整体休眠**（见 §6）：proc 钩子已由工程 T4 补齐（不再静默忽略）；但 `index.html` 无 GLTFLoader → `GLBSlots.enabled()` 恒 false，全部走程序化。启用真 GLB 需产品侧 ADR（构建/importmap）。
2. **`rooftop.side` 必须 `'west'`**（详见 §4 与文件头注释）。`'east'` 坡道不可达。
3. **坐标语义**：model 建筑 `x/z` = 西南角且 `ry` 不旋转碰撞盒（本图一律 `ry:0`）；proc 建筑 `x/z` = 中心且须满足 `h === floors*floorH`（B1 6=2×3、B2 10.5=3×3.5、B7/B8 6=2×3，已校验通过）。
4. **纹理键无 `'sand'`**：本图走工业主题，以 `metal`/`concrete`/`asphalt` 为主，不需沙色。
5. 夜景保底可视度依赖 `ambient.intensity:0.46`——低于此值近战会"瞎"，调参时勿过度压低。
