# 缩圈视觉规格（美术圣经 · 附录 H）

> 项目：战地突击 Battleground Tactical FPS（Three.js r160）
> 对应实现：v1.3 缩圈系统（工程侧 `js/mechanics.js` 扩展 or 独立模块）；数据由 `design/maps/zone-design.md`（design-strategist 定稿）提供
> 关联：`art/mechanics-visual.md`（既有机制视觉 = 本文档的同族规格）、`art/accessibility.md`（形状编码 + 红蓝三态色红线）、`art/theme-atmosphere.md`（三图雾/光照）、`js/ui.js`（小地图 canvas 2D 动态层）、`index.html`（#vignette / #lowhp / #radio）
> 本文档只给视觉参数，不改代码。**缩圈颜色永不等于红/蓝/中立三态色（accessibility §4 红线）**，且**不得与受击红闪（#vignette）、低血量（#lowhp）、炮击警示红（#ff4757）混淆**。

---

## 0. 设计原则

1. **圈是「全局环境层」，不是队伍层**：它不属于蓝/红任何一方。因此**禁止使用队伍蓝 `#5aa9ff`（normal）/ `#4dc3ff`（cvd）**——否则蓝方玩家会把圈误读为友军安全区，红方玩家误读为敌军区域。
2. **白 = 安全语义，电蓝 = 预告/收缩语义**（吃鸡惯例双圈），白是中性色不与任何队冲突；电蓝刻意压深压饱和，与队伍蓝/中立灰在明度+色相双轴分开。
3. **形状是主信道**：当前圈=实线细环，预告圈=虚线环（色盲安全，灰度可辨）。
4. **圈必须 `MeshBasicMaterial` + `fog:false`**：Basic 不受光（夜港断电/沙暴期仍可见），`fog:false` 保证沙暴雾 far=70、夜港雾 40/200 下圈不被雾吃掉（现状据点环未设 fog:false，是既有缺口；缩圈**必须**设，见 §6 风险）。
5. **光敏安全**：圈静态不闪烁；收缩指示用低频慢动（≤0.5Hz）或静态箭头，不做高频脉冲（accessibility §2 光敏红线 ≤3Hz）。

## 1. 3D 地面圈（当前圈 + 预告圈双层）

### 1.1 几何与材质

| 视觉项 | 规格 |
|--------|------|
| **当前圈（白·安全区）** | `RingGeometry(R-0.5, R+0.5, seg)`，`MeshBasicMaterial` 色 `0xf0f4f8`（白），`opacity 0.85`，`side:DoubleSide`，`depthWrite:false`，**`fog:false`**。`seg` 按半径自适应：`seg = clamp(ceil(2πR/4), 64, 192)`（据点 r=6 用 32 段尚可，圈 R≥50 时 32 段每段折线 >9m 会明显；R=130 时 128 段 → 每段 ≈6.4m，视觉平滑） |
| **当前圈辉光层** | 第二层 `RingGeometry(R-2.2, R+2.2, seg)`，同白，`opacity 0.12`，`depthWrite:false`，`fog:false` —— 无后处理管线下的「边缘光效」替代（双层环 = 亮线 + 光晕） |
| **预告圈（电蓝·下阶段落点）** | `RingGeometry(R2-0.6, R2+0.6, seg2)`，`MeshBasicMaterial` 色 `0x2f7fe8`（电蓝，深于队伍蓝），`opacity 0.9`，`DoubleSide`，`depthWrite:false`，`fog:false`。**虚线实现**：用 24 个 `RingGeometry` 扇段（每段 15°，间隔 3°）或 `RingGeometry` + 带透明段的程序化环贴图（与据点虚线环方案同源，见 mechanics-visual §3 炮击扇段的确认结果） |
| **地面高度** | 双层环 `y = 0.18`（略高于据点环 0.06 / 炮击环 0.15，避免 z-fighting；圈是大面积地面层，抬高一点不穿掩体） |
| **刻度增强（可选 P1）** | 圈上等距 8 个白色小刻度块（`BoxGeometry(0.6, 0.04, 1.4)`，Basic 白），像时钟刻度 → 增强轮廓识别 + 收圈时判断「哪一侧在靠近」 |

### 1.2 收缩过渡动画

| 阶段 | 行为 |
|------|------|
| **预告期（WARN）** | 当前圈（白，目标位置）常驻；预告圈（电蓝虚线）从**当前半径**缩向**下阶段半径**，2s easeInOut（`U.easeOut` 收尾）。缩圈动作=电蓝虚线环半径缩小到目标（白圈内侧），玩家「跟着白圈跑」 |
| **收缩期（SHRINK）** | 电蓝虚线环继续收缩至白圈半径，随后电蓝环 `visible=false`；白圈**不缩放**（白圈始终是目标安全区，位置不变直到下一阶段） |
| **环重建** | 收缩动画期间每帧按半径重建 `RingGeometry`（BufferGeometry 重建成本低；R=130 时 128 段 ≈ 8k 顶点，2s×60fps = 120 次重建可接受）。工程若担心 GC，可预建 32/64/128 三档几何池，按 R 取整档位缩放（缩放会让环宽略变，视觉可接受） |
| **方向指示（P1）** | 收缩时在电蓝环上放 4 个旋转光点 Sprite（复用 `FX.flashTex`，色 `0x2f7fe8`，opacity 0.35），沿收缩方向缓慢漂移（≤0.5Hz），或静态：环上 4 个三角箭头贴图指向圆心 |

> ⚠ **视觉口径**：收圈时**白圈位置不动、电蓝圈动**——玩家看到「蓝圈缩向白圈」，这与吃鸡惯例一致，也天然把「预告目标」与「收缩过程」分成两个视觉层，避免误读。

## 2. 小地图圈样式（canvas 2D 动态层）

接入点：`ui.js` MiniMap.draw()，在**据点绘制之前**画圈（圈在最底层，据点/单位/机制标记叠在圈上，保证据点信息不被圈遮）。

| 元素 | 绘制 |
|------|------|
| **当前圈（白）** | `strokeStyle '#f0f4f8'`，`lineWidth 1.5`，`arc(R*s)` 实线 stroke；填充 `rgba(240,244,248,0.05)`（极淡，不遮底图道路） |
| **预告圈（电蓝虚线）** | `strokeStyle '#2f7fe8'`，`lineWidth 1.2`，`setLineDash([5,4])`，`arc(R2*s)` stroke；**无填充**（虚线即「未生效」，与实线「生效中」区分） |
| **填充优先级** | 圈填充 < 沙暴底色 `rgba(202,160,106,0.18)`（沙暴期圈仍可辨：白实线/电蓝虚线在沙底之上）；圈填充 < 据点圆环（据点信息最高层） |
| **收缩箭头（P1）** | 预告圈上画 4 个指向圆心的小三角（电蓝），收缩期显示 |

> 小地图静态底图 188×188、比例 `s = 188/CFG.WORLD`，圈半径直接 `R*s`，三图通用（port 260 / suburb 300 / desert 340）。

## 3. 圈外伤害屏边缘警示（vignette）

### 3.1 与既有红伤的区分（必须）

| 现有元素 | 颜色 | 用途 | 缩圈警示不得复用 |
|----------|------|------|------------------|
| `#vignette` | 红 `rgba(255,0,0,.38)` | 受击闪红（flashDmg，220ms 瞬闪） | ✗ |
| `#lowhp` | 深红 `rgba(180,0,0,.4)` | 低血量常驻 | ✗ |
| 炮击警示环 | 亮红 `#ff4757` | 落点危险区（短促、局部） | ✗ |

**缩圈警示 = 新增电蓝 vignette**，语义「环境伤害 · 持久 · 全局」，与「瞬时受击红」「落点红」完全分开。

### 3.2 规格

| 视觉项 | 规格 |
|--------|------|
| **新元素** | 建议新增 `#zoneVignette`（或工程按需复用/扩展 vignette 支持多色参数）。`background: radial-gradient(ellipse at center, rgba(47,127,232,0) 55%, rgba(47,127,232,0.42) 100%)`，`pointer-events:none`，`inset:0` |
| **强度随圈外深度递增** | `opacity = clamp((distOut)/60, 0.12, 0.45)`，`distOut` = 玩家距当前圈边界的水平距离（m）。越靠外越浓 → 玩家「往圈内走一点，红（蓝）就淡一点」的即时反馈 |
| **常驻 vs 脉冲** | 圈外 = 常驻静态（不闪）。可加极低频呼吸 `opacity *= 1 + 0.05·sin(π·t)`（≤0.5Hz，光敏安全），可选 |
| **方向引导（P1）** | 边缘叠加 4 个指向圈心的白色半透明箭头（CSS 或 canvas 上屏），帮助玩家找圈方向（尤其 port 夜景/desert 沙暴期） |
| **色盲模式** | 电蓝 `#2f7fe8` 在 CVD 下仍是「深蓝/深青」，与红 `#ff4757`（protan/deutan 下偏棕暗红）可辨；但**不单靠颜色**——vignette 形状是「屏幕四周向中心渐变」+ 可开「圈外边缘加白色细描边」（accessibility §2 减少闪烁同开关处，加「圈外高对比边」选项） |

## 4. 阶段警示 UI（对接 #radio 顶部通知条）

复用现有 `#radio` 通道（`#radioState` 黄字/黄框 + `#radioFeed` 灰蓝副行），**不新增横幅层级**，与机制通知共用（沙暴/炮击/曝露同通道，按事件顺序覆盖）。

| 事件 | #radioState 文案 | #radioFeed 副行（灰蓝） |
|------|------------------|------------------------|
| 预告 30s（WARN 开始） | `⏳ 安全区即将缩小 — 30s` | `向圈内移动，圈外持续伤害` |
| 收缩开始（SHRINK） | `🌀 安全区缩小 — 向圈内移动！` | `跟着白圈跑，别被蓝圈追上` |
| 圈外受伤害 | 不重复刷屏（伤害反馈靠 vignette + 血条），仅首伤时 `⚠ 你已身处圈外！` | `进入安全区停止伤害` |
| 最终圈（可选） | `🔴 决战圈 — 最后一搏` | `圈外伤害剧增` |

- **颜色**：#radioState 维持现有警示黄 `#ffd166`（通道统一，不另开颜色语义）；图标（⏳/🌀/⚠）承担区分。
- **光敏**：通知条文字进场动画复用 `radIn`（0.15s），不新增闪烁。
- **文案归属**：最终文案与数值（30s 预告等）由 design-strategist zone-design 定稿；本文档只定视觉通道与样式。

## 5. 色盲安全（圈不单靠蓝）

| 信道 | 实现 | 灰度下可辨 |
|------|------|-----------|
| **颜色** | 当前圈白 `0xf0f4f8`（Y≈0.86）vs 预告圈电蓝 `0x2f7fe8`（Y≈0.19）——明度差 ≈ 4.5:1，远超队伍蓝红 2.66:1 的要求 | ✅ |
| **形状** | 实线环（当前）vs 虚线环（预告） | ✅ |
| **明度 vs 队伍色** | 电蓝 `0x2f7fe8` Y≈0.19 vs 队伍蓝 `#5aa9ff` Y≈0.378 vs 中立灰 `#707880` Y≈0.184 —— 电蓝比队伍蓝暗 2 倍，灰度下「圈 ≠ 蓝方」 | ✅ |
| **辅助纹理** | 环上 8 刻度块（白，P1）+ 收缩箭头 | ✅ |
| **CVD 模式** | 电蓝不随 `?cvd=1` 切换（圈是环境层，不是队伍层）；CVD 下队伍蓝变青 `#4dc3ff`、电蓝仍深蓝——形状（虚线/实线）+ 明度双保险 | ✅ |

> 验收：灰度截图下，白实线圈、电蓝虚线预告圈、红蓝据点三态、炮击红环**四类元素仍可互相区分**（accessibility §6 灰度测试扩展）。

## 6. 与既有机制视觉共存（不打架）

| 机制 | 冲突点 | 处理 |
|------|--------|------|
| **沙暴（desert）** | 风暴期雾 far=70，圈会被雾吃掉 | 圈**必须 `fog:false`**（第 0 节原则 4）。白/电蓝圈在沙黄雾中仍可见；小地图圈画在沙暴底色之上 |
| **探照灯断电（port）** | 断电 ambient 0.46→0.32 | 圈是 Basic 不受光，断电不暗；夜港本身低照度，白圈 Y≈0.86 是全图最亮元素之一，**恰好充当导航锚点** |
| **炮击警示（suburb）** | 红环 `#ff4757` 闪烁膨胀 vs 圈白/电蓝 | 色相（红 vs 白/蓝）+ 节奏（闪烁 vs 静态）+ 尺度（8m 局部 vs 全局圈）三重区分；圈实线/虚线结构与炮击扇段环（8 段）也不重复 |
| **据点三态** | 队伍蓝 `#5aa9ff` 与圈蓝 | 圈用深电蓝 `#2f7fe8` + 白当前圈双圈结构，灰度/色相双分离（§5） |
| **空投信标（suburb）** | 绿光柱/绿点 | 白/电蓝圈与补给绿 `#4ade80` 无冲突 |
| **HUD 红伤** | vignette 红色已占用 | 圈外警示独立电蓝 vignette（§3） |

**性能口径**：圈 = 2~4 个 RingGeometry mesh + 可选 8 刻度块 + 4 个箭头 Sprite，全图仅 1 组（不是每据点一份），远低于既有 4 探照灯锥 + 炮击环 + 空投信标的开销。收缩期每帧重建 1 个环（128 段 ≈ 8k 顶点），可接受；需工程确认 `RingGeometry` 重建不触发材质重编译。
