# 程序化纹理规格 + 建筑染色调色板（美术圣经 · 附录 E）

> 对应实现：`js/textures.js` — `Tex`（canvas 2D 程序化生成）；`js/models.js` — `BuildingLib`
> 交付对象：engineering-lead（T-02 纹理 key 实现、T-01/D-15 tint 字段实现）
> 本文档给出**可直接照 canvas API 实现**的参数规格，不写具体代码。

---

## 1. 现状速览

`Tex` 现有 8 个 key：`brick / concrete / grass / asphalt / sandbag / metal / floor / roof`。
**未知 key 静默回退 `concrete`**（`textures.js:89-90`）——这是 T-02 必须新增以下 4 个 key 的原因。

| key | 主题用途 | 现有替代 | 替代问题 |
|-----|---------|---------|---------|
| `sand` | desert 地形 / 土路 | `grass`（绿色草地） | 绿草地直接毁掉沙漠主题 |
| `plaster` | desert 建筑墙面 | `brick`（红砖） | 红砖把主题拉回欧洲 |
| `corrugated` | port 仓库 / 集装箱 | `metal`（横纹银灰） | 没有竖波纹立体感，像平板 |
| `rust` | port 钢结构 / 龙门吊 / 废铁 | `concrete`（灰） | 港口没有锈蚀就失去工业气质 |

## 2. 新增 4 个 key 的视觉规格

所有纹理画布 **256×256**（与现有 key 一致），`wrapS/T = RepeatWrapping`，各项异性 4。

### 2.1 `sand`（沙地 / 土路）—— 用于 desert

| 属性 | 值 |
|------|-----|
| 底色 | `#c2a26a`（= desert `terrain.colors[0]`） |
| 大尺度沙纹 | 6–8 条横向椭圆带，`#b08f57` 透明度 0.06–0.14，宽轴 120–220 / 短轴 10–26 |
| 亮斑 | 5–6 条 `#cdb07a` 椭圆带，透明度 0.06–0.12 |
| 细沙粒 | 4000 个 1–2 px，`#8a7340`，透明度 0.06–0.20 |
| 小石 | 30 个 2–4 px，`#6e5a37`，透明度 0.20–0.50 |
| 平铺建议 | 地形 `repeat ≈ 40`；土路 `repeat ≈ 30` |

**辨识特征**：近看是均匀米黄细粒，远看有横向沙纹——这是「沙丘」不是「工地地面」。

### 2.2 `plaster`（灰泥墙）—— 用于 desert 建筑墙面

| 属性 | 值 |
|------|-----|
| 底色 | `#cbb188`（= desert 土坯墙主色） |
| 抹灰不均斑块 | 16–20 个大圆弧（半径 20–60），亮侧 `#c8b282` 0.05–0.14 / 暗侧 `#a89064` 0.05–0.12 |
| 抹痕 | 10–14 条 1 px 水平短弧线，`#967e56`，透明度 0.15（弧度随机） |
| 细颗粒 | 2000 个 1 px，`rgba(0,0,0)` 透明度 0.02–0.06 |
| **关键约束** | **没有砖缝线、没有条纹** —— 与 `brick` 的唯一区别就是「平」 |
| 平铺建议 | 墙面 `repeat ≈ w/8` |

**辨识特征**：平整、轻微斑驳、低噪声。玩家一眼看出「这是砌出来的墙」而不是「铁皮/砖」。

### 2.3 `corrugated`（波纹钢板）—— 用于 port 仓库 / 集装箱

| 属性 | 值 |
|------|-----|
| 底色 | `#566069`（冷铁灰） |
| 竖波纹 | 每 8 px 一个周期：3 px 亮带 `rgba(255,255,255,0.08)` + 3 px 暗带 `rgba(0,0,0,0.12)`（即凸/凹各 3 px，中间隔 2 px 过渡） |
| 锈斑 | 50 个，`#7a4a32`，透明度 0.08–0.28，**偏向底部**（y ∈ [200,256]）模拟积水锈蚀 |
| 金属高光 | 500 个 1 px，`#e6ebf0`，透明度 0.02–0.06 |
| 平铺建议 | 墙面 `repeat ≈ w/4`（波纹密，必须低 repeat 否则糊） |

**辨识特征**：竖条纹 + 底部锈线 = 「港口仓库」，与 `metal`（横纹银灰平板）形成明确区分。

### 2.4 `rust`（锈蚀金属）—— 用于 port 钢结构 / 龙门吊 / 废铁

| 属性 | 值 |
|------|-----|
| 底色 | `#6e4a35`（深锈红褐） |
| 锈斑 | 150 个 2–12 px，三色随机：`#8a5a3a` / `#5a3a28` / `#b06a3a`，透明度 0.08–0.30 |
| 深色鳞片 | 60 个 2–6 px，`#4a2f22`，透明度 0.15–0.40 |
| 新鲜橘锈 | 30 个 1–4 px，`#be763a`，透明度 0.10–0.35 |
| 颗粒 | 3000 个 1 px，`rgba(0,0,0)` 透明度 0.03–0.10 |
| 平铺建议 | `repeat ≈ w/6` |

**辨识特征**：高密度锈斑 + 橘色点缀，比 `corrugated` 更「废」。

## 4. 建筑染色调色板（T-01 / D-15 的 `buildings[].tint`）

### 4.1 字段规则

- 字段：`buildings[].tint: 0xrrggbb`，**默认 `0xffffff` = 不染色**（three.js 中 `material.color` 与顶点色**相乘**，白色乘任何颜色 = 原色）。
- 实现：`placeModelBuilding` 里找到主体材质，`mat.color.setHex(tint)` 即可；tint 只作用于主体（`BuildingLib` 网格），**不作用于**程序化精修 trim（trim 已有 `detailTex` 可控）。
- **只做整体偏移，不做分区染色**（分区是纹理/顶点色的事）。

### 4.2 tint 亮度红线

`tint` 是乘法因子，**各 RGB 通道必须落在 [0.55, 0.90]**：
- < 0.55 → 原建筑暗部（顶点色 ~0.3–0.4）乘完 ≈ 0.2 → 死黑，夜景/背光面不可见
- > 0.90 → 染色效果趋近于零，等于没调

### 4.3 推荐值表

| 主题 | 建筑 | tint | 意图 |
|------|------|------|------|
| **suburb**（基准） | 全部 | `0xffffff` | 不染色，原色即基准 |
| **port**（冷压） | warehouse | `0x8fa0ad` | 冷灰蓝，抹掉暖砖 |
| | apartment | `0x8c97a3` | 同上 |
| | house | `0x9aa3ab` | 微提亮（民居体量小，需要更亮） |
| | watchtower | `0x9aa0a6` | 木色冷压 |
| | **cover** | `0xffffff` | **中性锚点，永不 tint** |
| **desert**（暖推） | warehouse | `0xd8c49a` | 土黄 |
| | apartment | `0xd0b58c` | 土黄（略深，与 warehouse 区分） |
| | house | `0xe0cba4` | 亮米（民居更亮） |
| | watchtower | `0xc9b082` | 暖木 |
| | **cover** | `0xffffff` | **中性锚点，永不 tint** |

**验证样例**（三图同一栋 house 在 30m 处截图对比）：suburb 应偏中性/暖砖、port 明显偏冷蓝、desert 明显偏土黄——三者一眼可辨且都保有细节（不致死黑）。
